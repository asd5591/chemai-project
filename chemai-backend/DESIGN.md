# ChemAI 前端视觉设计规范（DESIGN.md）

> AI 写前端时**必须遵守**的可执行设计约束。来源：`docs/设计文件/35-设计系统.md`（设计系统）与 `38-前端页面设计规格.md`（页面规格）。
> 后续所有前端页面开发（文档 44 起）以此为视觉依据；验收阶段（文档 58）对照本文件检查。
> 句式约定：**必须** = 强制执行；**禁止** = 一经出现即为不合格。

---

## 一、色彩系统

### 1.1 主色

| 令牌 | 色值 | 用途 |
|---|---|---|
| 主色 Oxford Blue | `#002147` | 主按钮、侧边栏、标题栏、标题强调、移动端激活 Tab |
| 主色悬停 | `#001a38` | 牛津蓝按钮悬停态 |
| 辅助色 Teal | `#0d7377` | AI 按钮、AI 相关强调、辅助按钮、化学元素强调 |
| 辅助色悬停 | `#0a5c5f` | 学术青按钮悬停态 |
| AI 气泡底色 | `#e0f2f1` | 学生端 AI 对话气泡浅青底 |

- 按钮主色必须使用 `#002147`，悬停加深为 `#001a38`；AI 按钮必须使用 `#0d7377`，悬停加深为 `#0a5c5f`
- 必须用颜色区分信息来源：Oxford Blue = 系统的声音（导航/按钮/标题），Teal = AI 的声音（对话气泡/智能建议）
- 禁止在页面中直接硬编码本文件之外的颜色值；禁止把 Teal 用于系统 UI、把 Oxford Blue 用于 AI 对话

### 1.2 中性色

| 令牌 | 色值 | 用途 |
|---|---|---|
| 主背景 | `#f7f9fc` | 页面底色（冷调） |
| 表面色 | `#ffffff` | 卡片、弹窗底色 |
| 浅灰面 | `#f1f5f9` | 侧边栏、分区底色、悬停底色 |
| 正文色 | `#0f172a` | 所有正文文字 |
| 次要文字 | `#475569` | 辅助说明、时间戳、标签 |
| 弱化文字 | `#94a3b8` | 占位符、禁用态文字 |
| 边框 | `#e2e8f0` | 卡片边框、分割线、表格线 |
| 强边框 | `#cbd5e1` | 输入框聚焦、强调分割 |
| 链接蓝 | `#2563eb` | 超链接、次要强调 |

- 页面主背景必须使用 `#f7f9fc`，信息层级必须靠明度差表达；禁止用纹理、渐变装饰表达层级

### 1.3 语义状态色（浅底深字标签式）

| 状态 | 背景色 | 文字色 | 场景 |
|---|---|---|---|
| 成功/通过 | `#e7f2ec` | `#2c6e49` | 审核通过、答案正确 |
| 警告 | `#fdf3e3` | `#b45309` | 审核警告、需人工复核 |
| 错误/阻断 | `#fbeae7` | `#b43c28` | 审核阻断、错误提示、删除操作 |

- 语义状态必须以"浅色背景 + 深色文字"的标签呈现；错误红必须使用 `#b43c28`、成功绿 `#2c6e49`、警告橙 `#b45309` 作为文字色
- 禁止使用纯色填充大面积呈现语义状态；禁止自定义其他红/绿/橙色值

### 1.4 障碍类型标签色（平行无等级）

| 障碍类型 | 色值 |
|---|---|
| 概念理解型 | `#7B2D8E`（紫） |
| 审题障碍型 | `#3B5BA5`（蓝） |
| 表述障碍型 | `#00897B`（青） |

- 三种障碍色必须平行使用，禁止暗示等级关系
- 难度标签必须遵循"绿→蓝→红"递进：简单=青绿、中等=蓝、困难=红

### 1.5 图表配色

- 图表（ECharts）系列色必须按序取自：`#002147` → `#0d7377` → `#2563eb` → `#2c6e49` → `#b45309` → `#b43c28`
- 状态类图表（通过率、审核结果）必须复用 1.3 的语义色；禁止引入品牌色板之外的新色相

## 二、字体与字号

### 2.1 字体

- 中文正文必须使用系统字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`
- 化学式、代码、数据等宽场景必须使用 `JetBrains Mono`（后备 `Consolas, monospace`）；化学式上下标必须等宽对齐
- 禁止引入任何外部 Google Fonts / 网络字体依赖（本地无网络字体，加载必须零依赖）

### 2.2 字号

| 层级 | 字号 | 字重 | 场景 |
|---|---|---|---|
| 页面主标题 | 24px | 600 | 登录页 Logo 文字等 |
| 区块标题 | 20px | 600 | 卡片组标题 |
| 卡片标题 | 16px | 600 | 卡片标题、列表行主文字 |
| 正文 | 14px | 400 | 默认正文、表格内容 |
| 辅助文字 | 12px | 400 | 时间戳、占位符、说明 |

- 字号必须取自上表五档，禁止使用 13px/15px 等表外值
- 正文行高必须 ≥1.5；标题行高必须 ≥1.3

---

## 三、间距与布局

- 间距必须基于 8px 网格，取值仅限：4 / 8 / 16 / 24 / 32px
- 卡片内边距必须为 24px；卡片之间间距必须为 16px
- 页面主内容区左右留白：桌面 ≥24px；移动端必须为 16px
- 禁止使用 5px、13px 等表外间距值；禁止用空格字符（`&nbsp;`）代替间距

---

## 四、圆角与阴影

### 4.1 圆角（四档）

| 元素 | 圆角 |
|---|---|
| 按钮 | 8px |
| 卡片 | 12px |
| 弹窗 | 16px |
| 标签胶囊 | 9999px |

- 必须使用上表四档圆角，禁止其他圆角值

### 4.2 阴影（三级）

| 层级 | 规格 |
|---|---|
| 第一级（轻） | `0 1px 2px rgba(15, 23, 42, 0.06)` |
| 第二级（中） | `0 4px 8px rgba(15, 23, 42, 0.08)` |
| 第三级（重） | `0 12px 24px rgba(15, 23, 42, 0.12)` |

- 卡片默认无阴影、悬停时用第二级；弹窗必须用第三级
- 禁止使用彩色阴影（如 `rgba(0,33,71,…)` 以外的色相）

## 五、组件规范

### 5.1 按钮（六变体）

| 变体 | 视觉 | 用途 |
|---|---|---|
| 主按钮 | `#002147` 实底 + 白字 | 提交、生成、保存 |
| 次按钮 | `#002147` 描边 + 透明底 | 取消、返回、暂存 |
| AI 按钮 | `#0d7377` 实底 + 白字 | 智能出题、AI 诊断 |
| 渐变按钮 | 铜蓝→靛蓝→甲基绿渐变 | 开始批改、启动实验模拟 |
| 小按钮 | 主按钮缩小版 | 表格行内、卡片内联 |
| 图标按钮 | 纯图标无文字 | 关闭、刷新、设置 |

- 按钮圆角必须为 8px；悬停必须同时满足：颜色加深（主色 `#001a38`、青色 `#0a5c5f`）+ 轻微上浮阴影；点击必须有缩小按压反馈
- 禁用态必须为：背景 `#e2e8f0`、文字 `#94a3b8`、`cursor: not-allowed`，且移除悬停效果
- 登录按钮必须全宽、高度 48px
- 禁止用色值之外的任意红/绿做主按钮；禁止禁用态仍可触发点击事件

### 5.2 卡片（三变体）

- **标准卡片**：白底 `#ffffff` + 边框 `#e2e8f0` + 圆角 12px + 内边距 24px，悬停加第二级阴影
- **强调卡片**：顶部 4px Oxford Blue 装饰条（用于当前进行中的考试等）
- **语义强调卡片**：浅底深字 + 左侧强调边距线（传达通过/警告/阻断）

### 5.3 表单

- 标准输入框：浅灰边框 `#e2e8f0`、圆角 8px；聚焦时边框变 `#2563eb` 并出现淡蓝色光晕
- 极简输入框：无边框、仅底部 2px 灰色实线（对话输入、内联编辑专用）；聚焦时底线变 `#2563eb`
- 密码输入框必须带右侧眼睛图标切换可见性
- 禁止去掉输入框聚焦态样式

### 5.4 标签 / 徽章

- 必须使用"浅色背景 + 深色文字"胶囊样式（圆角 9999px）
- 审核标记三态：全部通过=绿底四维 ✓；部分警告=黄底对应维度 ⚠；阻断=红底对应维度 ✗；阻断题目禁止下发学生端

### 5.5 图表

- 图表库必须统一使用 ECharts；配色见 1.5
- 学情面板必须含 KPI、趋势、分布类图表；坐标轴与网格线必须使用 `#e2e8f0`

### 5.6 弹窗与通知

- 弹窗三层：半透明遮罩 → 白色卡片（圆角 16px）→ 底部按钮区（确认/取消右对齐）
- 操作反馈必须用右上角浮出通知（`#002147` 底白字，3 秒自动消失）；通知禁止阻断用户操作，需要确认的场景必须用弹窗

### 5.7 状态占位

- 空状态：半透明烧杯图标 + 引导文字（必须告知用户"可以做什么"，禁止只显示"暂无数据"）
- 加载状态：三点依次弹跳动画；错误状态：红色描述 + 重试按钮

## 六、响应式断点

| 场景 | 断点 | 布局 |
|---|---|---|
| 教师端桌面 | ≥1024px | 三栏：侧边导航（232px）+ 主内容区 + AI 对话面板 |
| 教师端小屏 | 768–1023px | 两栏：侧边栏折叠仅图标；AI 面板隐藏，按钮呼出 |
| 学生端 / 家长端 | <768px | 单栏移动端：顶部标题栏 56px + 内容区 + 底部 TabBar 56px |

- 教师端侧边栏必须固定 232px；学生端抽屉必须 280px；学情详情抽屉必须 480px
- 学生端与家长端必须按 430px 移动视口设计；顶部标题栏与底部 TabBar 高度必须为 56px（对话输入区 70px）
- 底部 TabBar 为 4 Tab（AI 助教/练习/错题/我的），激活态必须为 Oxford Blue
- 禁止在移动端页面使用固定像素宽度的横向滚动布局

---

## 七、化学式渲染

- 化学式必须等宽渲染（JetBrains Mono）；API 返回的纯文本化学式（H2O、SO4^2-）必须转换为带上下标格式（H₂O、SO₄²⁻）后再展示
- 化学方程式必须通过 KaTeX + mhchem 渲染（`\ce{...}` 语法）；禁止用 `<sub>` 手工拼复杂方程式（可逆号、沉淀符号、配平系数场景）

---

## 八、硬性禁止清单（验收红线）

1. 禁止硬编码本文件之外的色值、圆角、阴影
2. 禁止引入外部网络字体与 CDN 之外的前端依赖
3. 禁止绕过语义色体系自造红/绿/橙
4. 禁止阻断式通知（应通知的场景不得用弹窗，应确认的场景不得用通知）
5. 禁止阻断题目进入学生端任何视图
6. 禁止移动端出现横向滚动；禁止桌面端页面宽度无上限拉伸（内容区最大宽度必须受限）
7. 禁止化学式以纯文本直出（必须转上下标或 KaTeX 渲染）
